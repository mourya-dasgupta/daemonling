# daemonling (`dmn`)

A tiny daemon that lives on your focus — a virtual pet for your terminal. Focus sessions feed it,
streaks teach it tricks, and weeks of work evolve it into a species shaped by how you work. It never
dies, and it never sends your data anywhere.

```bash
dmn init --name Pixel
dmn start          # 25-minute focus session with a live countdown
dmn status
dmn --help
```
